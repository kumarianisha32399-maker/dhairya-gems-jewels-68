# Continue Dhairya Gems & Jewels

## Goal
Continue the existing GitHub jewellery-store project in place, preserving its product photography, prepared sample data, premium brand direction, and frontend-only demo requirements.

## Work plan
1. Bring the existing GitHub project's jewellery data, product types, and assets into this project without replacing the app or its Git history; document the continuation in the project roadmap.
2. Build the shared storefront frame and persistent demo-store data, then add the public shopping, collection, product, editorial, contact, and checkout pages.
3. Add the demo admin login, a responsive protected dashboard and management pages with visible Add/View/Edit/Delete actions and saved changes.
4. Add any missing Vercel deployment setup, fill page-specific metadata, and verify the preview, key shopping/admin paths, and automated tests.

## Technical notes
- Keep the existing TanStack Start, React, Vite, and Tailwind foundation; do not replace the project with another app or framework.
- Use mock content and browser storage only; do not add a database, real payments, or real account authentication.
- Reuse the repository's image and product data while keeping business claims and credentials within the supplied demo brief.
